# SCA Frontend Project Overview

## Purpose
SCA Frontend (Static Code Analysis Frontend) is a React-based web application that provides an IDE-like interface for static code analysis. It includes features like:

- Code editor with syntax highlighting and tabs
- File browser/project structure viewer  
- Problems/issues viewer for static analysis results
- Statistics dashboard
- System design tool for creating architectural diagrams
- Authentication system

The application is designed as a frontend for static code analysis tools and is deployed at: https://diploma-works.github.io/sca-frontend/

## Target Audience
This appears to be a diploma/thesis project (based on the GitHub organization "Diploma-works") focused on creating a comprehensive static code analysis platform with a user-friendly interface.

## Key Features
1. **Code Editor**: Multi-tab editor with syntax highlighting
2. **Project Structure**: Tree view of project files and folders
3. **Problems Panel**: Display static analysis issues and warnings
4. **Statistics**: Analytics and metrics dashboard  
5. **System Design**: Tool for creating system architecture diagrams
6. **Authentication**: User login/auth system
7. **Theming**: Light/dark mode support
