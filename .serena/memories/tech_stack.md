# Technology Stack

## Frontend Framework
- **React** (v18.2.0) - Main UI framework
- **React Router DOM** (v6.23.1) - Client-side routing
- **React Scripts** (v5.0.1) - Build tooling and development server

## UI Framework & Components
- **Material-UI (MUI)** (v5.15.4) - Primary UI component library
  - @mui/material - Core components
  - @mui/icons-material - Icon library
  - @mui/x-charts - Charts and data visualization
  - @mui/x-tree-view - Tree view components
- **Emotion** - CSS-in-JS styling (used by MUI)

## Authentication
- **React Auth Kit** (v3.1.3) - Authentication management
- **@auth-kit/react-router** (v3.1.3) - Router integration for auth

## Drag & Drop
- **@dnd-kit** - Modern drag and drop toolkit
  - @dnd-kit/core (v6.1.0)
  - @dnd-kit/sortable (v8.0.0)
  - @dnd-kit/utilities (v3.2.2)

## Diagramming & Graphics
- **@joint/core** (v4.1.3) - Diagramming library for system design

## Additional Libraries
- **react-icons** (v5.0.1) - Icon library
- **react-syntax-highlighter** (v15.5.0) - Code syntax highlighting
- **overlayscrollbars-react** (v0.5.5) - Custom scrollbars

## Build Tools & Development
- **Create React App** - Bootstrap and build configuration
- **ESLint** - Code linting
- **Sass** (v1.89.2) - CSS preprocessing
- **Webpack** - Module bundler (via react-scripts)
- **@svgr/webpack** (v8.1.0) - SVG to React component transformation

## Deployment
- **GitHub Pages** (gh-pages v6.1.1) - Static site hosting
- Homepage: https://diploma-works.github.io/sca-frontend/

## Testing
- **Jest** - Testing framework (via react-scripts)
- **@testing-library/react** (v13.4.0) - React testing utilities
- **@testing-library/jest-dom** (v5.17.0) - DOM testing matchers
- **@testing-library/user-event** (v13.5.0) - User interaction testing
